1. Diagram Skema Entitas Relasional (ERD)

Visualisasi entitas tabel, tipe data, dan relasi key di Firebase Realtime Database

Format: JSON NoSQL Tree
Firebase Realtime Database (ROOT) / asia-southeast1
/monitoring
Live State (1:1)
Tabel penampung data live detik ini. Di-overwrite otomatis tiap kali ada paket LoRa baru masuk.
nodeId String ("TX-01")
level Int (0=Aman, 1=Waspada, 2=Bahaya)
temp Float (°C dari DHT22)
hum Float (% RH dari DHT22)
gasAO Int (0 - 4095 Analog ADC MQ-2)
gas Int (0: Low / 1: High Digital)
flame Int (0: Padam, 1: Api Aktif)
flameAO Int (0 - 4095 ADC Flame)
rssi Int (Kekuatan Sinyal dBm)
lastUpdate String ("16:45:10")
/logs/{push_id}
Time-Series History (1:N)
Tabel riwayat anomali & kebakaran. Rekaman baru selalu ditambahkan (Append) dan tidak dihapus.
log_id [PK] String (Unique Key Firebase)
timestamp String ("2026-11-13 16:50:00")
nodeId String ("TX-01")
level Int (1=Waspada, 2=Bahaya)
temp Float (°C saat kejadian)
hum Float (% saat kejadian)
gasAO Int (Kadar gas pemicu)
flame Int (Status api saat insiden)
rssi Int (Kekuatan Sinyal dBm)
note String ("Bahaya: Api Terdeteksi")
Relasi: 1 Realtime State mentrigger N Records Riwayat saat terjadi anomali level >= 1.
Database Engine: Firebase Realtime DB
